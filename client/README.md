# EventBook Frontend

This is the frontend application for the EventBook booking app built with React and Tailwind CSS.

## Features

- Browse and search events
- Filter events by category
- Book event tickets
- User authentication (login/signup)
- Dark mode support

## Tech Stack

- React
- React Router
- Tailwind CSS
- Context API (for auth and state management)
- Axios (for API requests)

## Prerequisites

- Node.js (>=14.x)
- npm or yarn
